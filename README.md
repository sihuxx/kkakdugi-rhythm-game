# 꺅두기 러닝비트 🍀

위에서 내려오는 네 줄 노트를 **A · S · K · L** 로 받아내는 웹 리듬게임. 옆에서는 꺅두기가 박자에 맞춰 같이 신나합니다.

브라우저만 있으면 돌아가고, 설치할 것도 서버도 없습니다.

## 어떻게 노나

| 조작 | 하는 일 |
| --- | --- |
| `A` `S` `K` `L` | 네 줄 노트 받기 (방향키도 됩니다) |
| 길게 누르기 | 쓰왜 — 롱노트를 끝까지 잡고 있기 |
| `WASD` / 방향키 | 집 안에서 걸어다니기 |
| `E` | 가구와 상호작용 |
| `Esc` | 일시정지 / 연출 건너뛰기 |

**키는 설정에서 바꿀 수 있습니다.** 집 위쪽 `설정` 버튼이나 일시정지 화면에서 들어가면 키 배치, 노트 속도, 싱크 보정(±150ms), 노래·배경음·효과음 볼륨을 따로 조절할 수 있어요. 일시정지를 풀면 3·2·1 카운트다운 뒤에 다시 시작합니다.

노트는 세 가지입니다 — **알약**(그냥 누르기), **긴 막대**(쓰왜, 끝까지 잡기), **별**(멜로디가 크게 뛰는 자리).
폰에서는 네 줄을 손가락으로 두드리면 되고, 두 손가락 동시도 됩니다. 집에서는 탭한 곳으로 걸어가요.

**집**에는 세 곳이 있습니다 — 옷장(두기 고르기), 상점(클로버 뽑기), 현관(노래 고르고 출발).

## 뭐가 들어있나

- **두기 18종** — 등급별로 나뉘고, 노래를 완주해 모은 클로버로 뽑습니다 (10연차 보장·천장 있음)
- **도감 보상** — 5종에서 클로버 300, 9종에서 노트 스킨 '딸기우유', 13종에서 '민트소다'와 클로버 500, 18종을 다 모으면 클로버 1500
- **창작 칩튠 4곡** — 외부 음원 없이 Web Audio API로 그 자리에서 연주합니다. 그래서 채보와 반주가 같은 데이터에서 나와 싱크가 원천적으로 안 어긋납니다
- **난이도 4단계** — 쉬움 / 보통 / 어려움 / 악몽. 레인은 음 높이로 정해져서, 멜로디가 올라가면 노트도 오른쪽으로 갑니다
- **뽑기 연출** — 두기들이 모여드는 인트로와 캐릭터별 공개 컷 (건너뛰기 가능)
- 곡마다 바뀌는 배경 (초원·비·밤하늘·사막)과 시간에 따라 변하는 하늘

## 실행

```
index.html 을 브라우저로 더블클릭
```

끝입니다. 빌드 과정도 의존성도 없어요. (글꼴만 인터넷에서 받아오고, 오프라인이면 시스템 글꼴로 대체됩니다.)

### GitHub Pages로 올리기

1. 이 폴더를 통째로 GitHub 저장소에 올립니다
2. 저장소 → **Settings → Pages**
3. Source를 **Deploy from a branch**, 브랜치는 `main` / 폴더는 `/ (root)` 로 지정
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 에서 열립니다

### 파일 하나로 묶기

```
python tools/build_single.py
```

`dist/ggakdugi-rhythm.html` 한 장이 나옵니다. 이미지가 전부 안에 박혀 있어서 그 파일만 보내도 그대로 돌아가요.

## 폴더 구조

```
index.html          화면 구조
css/style.css       전체 스타일
js/data.js          캐릭터 18종, 곡 4개, 난이도, 표지 그림
js/chart.js         채보 생성 — 멜로디에서 노트를 뽑아낸다
js/audio.js         Web Audio 반주·효과음
js/ui.js            상태, 화면 전환, 입력, 뽑기, 세이브
js/world.js         배경 테마·소품·입자
js/render.js        노트·캐릭터·집·뽑기 연출·메인 루프
assets/*.png        꺅두기 그림
tools/build_single.py  단일 파일 빌드
```

스크립트는 **읽히는 순서가 중요합니다** (data → chart → audio → ui → world → render). `index.html` 아래쪽 순서를 바꾸지 마세요.

## 곡 추가하기

`js/data.js`의 `SONGS` 배열에 한 덩어리를 더하면 됩니다. 마디는 8분음표 칸 단위이고, `[칸, 음이름, 길이, 'jump'?]` 네 칸짜리 배열로 적습니다.

```js
mkSong({
  id:'mysong', title:'내 노래', mood:'분위기 한 줄', bpm:120, spb:8,
  A:[ [[0,'C5',1],[2,'E5',1],[4,'G5',1],[6,'E5',1]], /* ...8마디 */ ],
  B:[ /* 4마디 */ ],
  wave:'square', cut:3000,
  chords:['C','G','Am','F', /* 마디 수만큼 */],
  kick:[0,4], clap:[2,6], hat:[0,2,4,6], theme:'meadow'
})
```

멜로디 하나만 적으면 반주와 네 난이도 채보가 자동으로 만들어집니다. `theme`은 `meadow` / `rain` / `night` / `desert` 중 하나, 표지는 `COVERS`에 SVG로 추가하세요.

실제 음원 파일(mp3)을 쓰려면 오디오 로딩과 offset 보정이 따로 필요합니다 — 그때는 `js/audio.js`의 스케줄러를 `decodeAudioData` + `AudioBufferSourceNode`로 바꾸고, 채보 JSON을 따로 두면 됩니다.
