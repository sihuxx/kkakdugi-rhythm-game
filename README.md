# 꺅두기 하우스 🍀

꺅두기를 **애기부터 어른까지 키우는** 웹 게임. 집에서 밥 주고 씻기고 재우면 두기가 자라고,
현관으로 나가 **설거지 알바**와 **배달 알바**를 뛰어 번 돈으로 가구를 사고 집을 넓혀갑니다.

브라우저만 있으면 돌아가고, 설치할 것도 서버도 없습니다.

```
index.html 을 브라우저로 더블클릭
```

## 놀이 흐름

**집에서 돌보기 → 알바로 벌기 → 사고 꾸미기 → 두기가 자람**

1. 아래쪽 **돌봄 버튼** 여섯 개로 밥 주기 · 씻기기 · 놀아주기 · 재우기 · 물 주기 · 청소하기
   (집 안 가구에 다가가 `E`로도 됩니다. 집은 `WASD`로 걸어다녀요)
2. 돌볼 때마다 **경험치**와 **애정도**가 오르고 스탯이 찹니다
3. 현관(`E`)이나 위쪽 **알바** 버튼으로 일하러 → **클로버 + 경험치**
4. 일하고 오면 배고프고 지저분해져요. 두기가 먼저 조르기도 합니다(들어주면 보너스 클로버)
5. 클로버로 **가구**를 사고 **집을 넓히고**(상점), **새 모습**을 뽑고(뽑기 기계) 옷장에서 갈아입혀요

### 성장 4단계

| 단계 | 필요 경험치 |
| --- | --- |
| 애기 두기 | 0 |
| 어린 두기 | 90 |
| 청소년 두기 | 280 |
| 어른 두기 | 700 |

자랄수록 화면 속 두기가 커지고, 꺅두기런에서도 그만큼 커집니다.

### 스탯 4가지 + 애정도

배부름 · 깨끗함 · 기분 · 기운. 평균이 **컨디션**이고, 여기에 **애정도**(돌볼 때마다 오르는 하트)가
더해져 알바 시급이 정해집니다 — 시급 배율 = 0.62 + 0.36 × 컨디션 + 0.18 × 애정도, 가구 보너스는
여기에 곱해집니다.

두기는 가끔 **먼저 조릅니다**(배고파요 / 심심해 / 졸려요…). 말풍선이 뜨고 해당 돌봄 버튼에 `!`가
붙는데, 그걸 해주면 보너스 클로버 35와 애정도가 올라갑니다. 스탯이 30 밑으로 떨어지면 머리 위에
느낌표가 떠요. 방이 더러워지면 먼지가 굴러다니고, 청소 버튼으로 치웁니다.

### 집 업그레이드

돈을 모으면 이사할 수 있어요. 방이 넓어지고 벽지·바닥·조명이 바뀌며 놓을 수 있는 가구도 늘어납니다.

| 집 | 값 | 달라지는 것 |
| --- | --- | --- |
| 낡은 방 | 처음부터 | 좁고 벽지가 들떴어요. 알전구 하나 |
| 아늑한 집 | 2,400 | 도배·마루 새로, 창문과 커튼, 가구 자리 9칸 |
| 넓은 집 | 7,000 | 창문 둘에 천장 몰딩, 펜던트 조명, 가구 자리 14칸 |

### 가구

상점에서 클로버로 삽니다. 사면 집에 알아서 자리를 잡고 효과도 붙어요 — 러그(기분 +2),
램프(잘 때 기운 +4), 책장(경험치 +8%), 낮은 탁자, 티비(놀아줄 때 기분 +5), 냉장고(밥 배부름 +6),
생일 케이크(경험치 +15%), 장난감 피아노(알바비 +8%), 소파, 액자·벽시계(알바비 +5%),
장식 깃발, 포스터, 작은 창문. 큰 가구는 집을 넓혀야 놓을 수 있습니다.

## 알바 ① 설거지 (분식집 주방)

노래에 맞춰 내려오는 **접시**를 **A · S · K · L** 로 받아 씻습니다. 곡 4개 × 난이도 4단계.

| 조작 | 하는 일 |
| --- | --- |
| `A` `S` `K` `L` | 네 줄 접시 받기 (설정에서 바꿀 수 있어요) |
| 길게 누르기 | 뽀득 — 긴 접시를 끝까지 문지르기 |
| `Esc` | 일시정지 (3·2·1 카운트다운 후 재개) |

네 곡 모두 이 페이지가 **직접 연주하는 창작 칩튠**이라 외부 음원이 없고, 채보와 반주가 같은
데이터에서 나와 싱크가 어긋나지 않습니다. 판정은 PERFECT / GREAT / GOOD / MISS.

## 알바 ② 배달 (동네 골목)

쿠키런 같은 2D 횡스크롤 러닝. 배달 가방을 메고 임시 맵 한 판(약 2,200m)을 달립니다.

| 조작 | 하는 일 |
| --- | --- |
| `Space` / `↑` / `W` | 점프 (공중에서 한 번 더 누르면 2단) |
| `↓` / `S` | 슬라이드 — 덩굴 밑을 지나갑니다. 공중에서 누르면 쿵 내려찍기 |
| `E` | 스킬 (게이지가 다 차면) |
| `Esc` | 그만두고 집으로 |

**동전**을 주우면 점수와 스킬 게이지가 차고, 체력 클로버 3개가 다 떨어지면 배달 실패.
배달할 집까지 도착하면 보너스를 받습니다. 덩굴은 점프로 넘을 수 없으니 **슬라이드**로 지나가세요.

**모습마다 스킬이 다릅니다** — 돌진(무적·장애물 파괴) / 폭신 점프(3단) / 젤리 자석 /
둥실둥실(활공) / 느긋느긋(느리게·젤리 2배) / 꽉 버티기(보호막).

## 뽑기와 옷장

뽑기 기계에서 클로버로 새 **모습**을 뽑습니다(1회 110, 10연차 1000). 10연차에는 귀함 이상이
하나 확정이고, 겹치면 클로버로 돌려받아요. 뽑은 모습은 **옷장**에서 갈아입힙니다 — 두기는
한 마리, 모습만 바뀝니다. 도감을 모으면 클로버와 노트 스킨을 받습니다(5·9·13·17종).

## 폰에서

돌봄은 아래 버튼을 그냥 누르면 되고, 방 안에서 가고 싶은 곳을 탭하면 두기가 걸어가요.
리듬게임은 네 줄을 손가락으로 두드리고, 꺅두기런은 화면 위쪽=점프 / 아래쪽=슬라이드,
아래 버튼으로도 됩니다.

## 파일 구조

```
index.html          화면 구조 (집 + 모든 화면이 한 페이지)
css/style.css       전체 스타일
js/boot.js          캔버스·크기·선 굵기 같은 공용 도구
js/data.js          모습 17종, 곡 4개, 난이도, 표지 그림
js/grow.js          성장 단계 · 집 단계 · 가구 · 돌봄 · 알바 · 런 스킬 표
js/save.js          세이브(ggakdugi.v2) · 클로버 · 경험치 · 스탯 · 애정도 · 요청 · 이사
js/chart.js         채보 생성 — 멜로디에서 노트를 뽑아낸다
js/audio.js         Web Audio 반주·효과음
js/world.js         리듬게임 배경 테마
js/menus.js         옷장 · 상점 · 뽑기 · 설정 · 알바 모달
js/cut.js           뽑기 연출 (인트로 → 공개)
js/home.js          집 — 방·가구 그리기, 자리 배치, 돌봄
js/rhythm.js        설거지 알바 (리듬)
js/run.js           배달 알바 (DugiRun 모듈)
js/app.js           셸 — 화면 전환, 입력, 메인 루프
assets/*.png        꺅두기 그림
tools/build_single.py  파일 하나로 묶기
```

스크립트는 **읽히는 순서가 중요합니다** (boot → data → grow → save → chart → audio → world →
menus → cut → home → rhythm → run → app). `index.html` 아래쪽 순서를 바꾸지 마세요.

### 파일 하나로 묶기

```
python tools/build_single.py
```

`dist/ggakdugi-house.html` 한 장이 나옵니다. 이미지가 전부 안에 박혀 있어서 그 파일만 보내도
그대로 돌아가요.

### GitHub Pages로 올리기

1. 이 폴더를 통째로 저장소에 올립니다
2. 저장소 → **Settings → Pages**
3. Source를 **Deploy from a branch**, 브랜치 `main` / 폴더 `/ (root)`
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 에서 열립니다

## 고치고 싶을 때

- **가구 추가** — `js/grow.js`의 `FURNITURE`에 한 줄 넣고(`row:1`이면 벽쪽 줄, `need:1`이면
  아늑한 집부터), `js/home.js`의 `drawFurn()` 스위치에 그리는 법을 추가하면 상점에 자동으로 나옵니다.
  자리는 `layoutHome()`이 줄마다 고르게 잡아줍니다
- **집 단계 추가** — `js/grow.js`의 `HOUSES`에 한 줄 (넓이·벽·바닥 색·가구 자리 수)
- **돌봄 종류 추가** — 같은 파일의 `CARE`에 넣고, 가구의 `act`를 그 이름으로
- **런 맵 고치기** — `js/run.js` 위쪽 `CHUNK`(덩어리 하나)와 `MAP`(이어 붙이는 순서).
  땅과 땅 사이를 비우면 구덩이가 됩니다. 한 번 점프로 높이 약 200 · 거리 330을 넘어요
- **곡 추가** — `js/data.js`의 `SONGS`에 `mkSong({...})` 한 덩어리. 멜로디만 적으면 반주와
  네 난이도 채보가 자동으로 만들어집니다
- **선 굵기** — 게임 안의 모든 선은 `js/boot.js`의 `LW()` 하나로 정해집니다
